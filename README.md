# Cherian James — 3D Artist, Motion Graphics & AI Video Creator Portfolio

A portfolio website crafted for **Cherian James** (Video Team Lead at BBP India, Kochi).

---

## 🌟 Key Features

1. **Interactive 3D WebGL / Canvas Hero Experience**
   - Native 3D geometric polyhedra (Icosahedron & Particle Constellation) rendered at Retina/4K resolution.
   - Reacts to mouse coordinates, touch swipes, and page scroll velocity with physics inertia.
   - Zero external CDN dependencies — works 100% offline.

2. **Cinematic Showreel Theater**
   - High-definition video player with ambient background glow reacting to video frames.
   - Dynamic discipline switcher:
     - 🚀 *Loco Balls 3D Confectionery Simulation* (Blender Cycles)
     - ⚡ *Seematti Luxury Brand Commercial* (Motion Graphics / Lead)
     - 🛠️ *Weber Grill 3D Exploded Assembly* (CAD/Mechanical Visualization)
     - 🛡️ *DRDO Aeroshow Defense Simulation* (Unreal Engine 5)
     - 🧠 *Generative AI Video Pipelines* (Runway Gen-3, ComfyUI, Topaz Video AI)
     - 🎵 *JBL GO Portable Speaker Audio Spot* (Kinetic Motion)

3. **Technical Topology & Lighting Breakdown Slider**
   - Interactive draggable before/after comparison slider.
   - Compares raw quad wireframe topology against the volumetric lit render.

4. **Filterable Works Grid & Interactive Lightbox**
   - Filter categories: `All Works`, `3D Art & CGI`, `Motion Graphics`, `AI Video & Neural`, `Commercial Campaigns`.
   - Hover video preview: Cards with videos automatically play smooth muted previews on hover.
   - Deep Case Study Modal: Detailed project breakdown, client specs, tools used, concept, and technical execution.

5. **Animated Scrolling & Interactions**
   - Staggered 3D perspective reveals with hardware acceleration.
   - 3D card tilt physics following cursor coordinates.
   - Live counting stats (3.5+ Years Exp, 50+ Commercials, 8.54 MFA CGPA).
   - Infinite kinetic typography marquee.

6. **Web Audio API Feedback Engine**
   - Crisp, futuristic UI sound synthesis (clicks, chirps, and whooshes) generated directly via browser code (zero external audio files needed).
   - Includes mute / unmute toggle in the top navigation.

7. **Contact & Commission System**
   - One-click copy email button with toast notification (`cherianjames5@gmail.com`).
   - Direct WhatsApp / Phone link (`+91 9061733697`).
   - Interactive inquiry form with project type selection.
   - Direct download link for `Cherian_James_Resume.pdf`.

## 🚀 How to View & Launch

### Instant Method:
Simply double-click `index.html` to open it in **Google Chrome**, **Microsoft Edge**, **Brave**, or **Firefox**!

### With Any Local Web Server:
If you prefer running a local server:
- With VS Code: Right-click `index.html` -> "Open with Live Server"
- With Python (if installed): `python -m http.server 8000`
- With Node (if installed): `npx serve .`

### Free 1-Click Hosting:
To publish this website live for free:
1. **GitHub Pages**: Push this directory to a GitHub repository, go to `Settings > Pages`, and select `main` branch.
2. **Vercel / Netlify**: Drag-and-drop the `Portfolio website` folder into [vercel.com](https://vercel.com) or [netlify.com](https://netlify.com) for instant global deployment with custom domain support.
